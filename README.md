# Christopher Ochoa Portfolio Website

A minimal, white portfolio site with separate pages for projects, about, resume, and contact.

## Run locally

```bash
python -m http.server 8080
```

Then open:

```text
http://localhost:8080
```

## Project details page

The Design Build Fly project now lives on its own page at `dbf.html` with:

- one featured project image on the projects page
- a full project summary
- the design report PDF
- all project photos
- project videos

## Edit these parts

- Name in the header
- Portrait image lives in `images/portrait_cropped.png`
- Homepage intro text
- Project titles and summaries
- DBF project details on `dbf.html`
- Resume link / PDF file name
- Email and LinkedIn links
